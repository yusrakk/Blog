# Bootstrap Blog Project

## Overview
This project is a simple blog template built using Bootstrap. It consists of a homepage, a blog page displaying articles in a 2-column layout, and an article page structured in a single column. The project also includes custom styles and JavaScript for enhanced functionality.

## Project Structure
```
bootstrap-blog
├── css
│   └── styles.css        # Custom styles for the blog and article pages
├── js
│   └── scripts.js        # JavaScript functionality for interactive elements
├── index.html            # Homepage of the blog
├── blog.html             # Blog page with articles in a 2-column layout
├── article.html          # Article page with a single column layout
└── README.md             # Documentation for the project
```

## File Descriptions
- **index.html**: Serves as the homepage of the blog, featuring links to blog articles and a list of recent posts.
- **blog.html**: Displays articles in a 2-column format using Bootstrap's grid system for responsive design.
- **article.html**: Represents the article page, including:
  - Article title
  - Article content
  - Share buttons
  - Navigation for previous and next articles
  - Recommendations for other articles
  - Visitor comments section
  - Comment submission form
- **css/styles.css**: Contains custom styles to enhance the appearance of the blog and article pages beyond Bootstrap's default styles.
- **js/scripts.js**: Includes JavaScript for interactive elements, such as comment submission and share button actions.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the homepage.
3. Navigate to `blog.html` to see the list of articles.
4. Click on any article to view it in `article.html`.

## Usage
Feel free to customize the styles in `css/styles.css` and add your own JavaScript functionality in `js/scripts.js` to enhance the blog experience.
